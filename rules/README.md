# Stack rules

Numbered self-checks per language. **On session start, read the rule file matching the project's dominant language** (typescript.md / python.md / go.md / rust.md / csharp.md / php.md) and apply its checks before declaring any task done. For multi-language repos, apply the rule of each language you touch.

Each rule file pairs with its `anti-slop-*` skill, which contains the full setup and gate commands.
